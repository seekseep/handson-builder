# __SITE_TITLE__

__SITE_DESC__ を **手を動かして学ぶ** ハンズオンリポジトリです。

各レクチャーのディレクトリには、その回のテーマを体験できる動くサンプルが入っています。アプリを起動して挙動を確かめ、コードを読み、必要なら直すまでが各レクチャーの流れです。

セクション・レクチャーの一覧、技術スタック、起動方法などの詳細は [sections/README.md](./sections/README.md) を参照してください。

## 構成

教材は 2 階層で整理されています。

- **セクション** — テーマで束ねた親ディレクトリ（`sections/01-.../` など）
- **レクチャー** — 1 つのハンズオン単位＝1 つの動くアプリ（`sections/01-.../01-.../` など）

学習者はレクチャー単位でディレクトリに移動し、その `LECTURE.md` に沿って手を動かします。

## 始め方

1. このリポジトリをクローンする
2. [セットアップ（Docker）](./sections/DOCKER.md) または [セットアップ（ホストマシン）](./sections/HOST.md) で環境を整える
3. [sections/README.md](./sections/README.md) の一覧から最初のレクチャーに進む
